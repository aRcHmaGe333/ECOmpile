# External Value Proof Kit

This document defines what external audiences should be able to verify directly.

## Core Value Claim

Convergent outcomes from real usage are compiled into deterministic execution paths under explicit review control.

## Public Verification Bundle

1. Reproducible pipeline run
- `ingest -> extract -> mine -> compile -> review -> route`

2. Deterministic behavior evidence
- known-intent kernel hit
- unknown-intent explicit fallback

3. Risk control evidence
- public-safe default output mode
- private evidence partition under `.private/`
- mandatory human final activation decision

4. Adaptation ownership evidence
- provenance audit report showing adapted implementation and no direct copy

## Minimal Public Packet

1. one-page architecture and module map
2. one-page contract and control summary
3. one-page benchmark/evidence summary
4. one-page provenance and governance summary

## Update Discipline

Each public update should include at least one measurable new signal:

1. improved deterministic hit rate
2. reduced fallback on known intents
3. lower manual review burden via grouped dilemmas
4. improved redaction and publication safety checks
